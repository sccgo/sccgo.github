# نُسُقِيبيديا — NUSUGIPEDIA
## الموسوعة الحرة المنظمة

---

### 📁 هيكل الملفات

```
nusugipedia/
├── index.html              ← الصفحة الرئيسية (SPA)
├── README.md               ← هذا الملف
├── css/
│   └── style.css           ← جميع الأنماط (CSS Variables + Responsive)
├── js/
│   ├── articles.js         ← قاعدة بيانات المقالات (7 مقالات)
│   ├── search.js           ← قاعدة بيانات البحث + الاقتراحات
│   └── app.js              ← المنطق الكامل للتطبيق (App Module)
└── assets/
    └── icons/
        └── favicon.svg     ← أيقونة الموقع
```

---

### 🚀 كيفية التشغيل

**الطريقة الأولى — فتح مباشر:**
```
افتح index.html مباشرة في المتصفح
```

**الطريقة الثانية — خادم محلي (مُوصى به):**
```bash
# Python
python -m http.server 8080

# Node.js
npx serve .

# ثم افتح: http://localhost:8080
```

### 📄 الصفحات المتوفرة

| الصفحة | الوصف |
|--------|-------|
| الرئيسية | مقالة مختارة، هل تعلم، الأكثر قراءة، آخر التغييرات |
| المقالات | ٧ مقالات كاملة: نسقيبيديا، ذكاء اصطناعي، كم، كون، عربية، ثقوب، كليوباترا |
| البحث | نتائج حقيقية مع اقتراحات وتمييز النص وفلاتر |
| تسجيل الدخول | نموذج دخول + إنشاء حساب + دخول اجتماعي |
| الملف الشخصي | إحصائيات + مساهمات + مراقبة + إعدادات |
| البوابات | ٨ بوابات معرفية |
| النقاش | تعليقات تفاعلية |

---

### ✨ الميزات

- **🔍 بحث حقيقي** مع اقتراحات فورية وتمييز النص ودرجات الصلة
- **🔐 دخول موحد** — تسجيل دخول / إنشاء حساب / Google / GitHub / Twitter
- **📱 متجاوب** — يعمل على جميع الأجهزة
- **🎨 تصميم ثنائي اللون** — أسود وأبيض بخطوط عربية فاخرة
- **⚡ SPA** — انتقال سريع بين الصفحات بدون تحميل
- **🌙 مؤشر التمرير** + زر العودة للأعلى
- **💬 نقاشات تفاعلية** مع نماذج الرد
- **⚙️ إعدادات المستخدم** مع toggle switches
- **🎲 مقالة عشوائية** من ٧ مقالات

### 📝 إضافة مقالة جديدة

في ملف `js/articles.js`، أضف مدخلاً جديداً:

```javascript
my_article: {
  title: 'عنوان المقالة',
  subtitle: 'ARTICLE TITLE · التصنيف',
  readTime: '١٠ دقائق',
  cats: ['تصنيف١', 'تصنيف٢'],
  content: `<p>محتوى المقالة هنا...</p>`
}
```

ثم في `js/search.js` أضف المقالة لقاعدة بيانات البحث.
